Privacy policy

OSW Teams backup is a private tool used only by its owner.

What it accesses

It asks Google for one permission: drive.file. With it, the tool can see and change only the files and folders it made itself in the owner's Google Drive. It cannot see any other file in that Drive, and it does not read email, contacts or any other Google data.

What it stores

Each night it uploads one backup file to a folder it made in the owner's Google Drive, and it removes its own old backup files. Each file is encrypted (AES-256) on the server before upload, with a key that only the owner holds. Google cannot read the files.

Sharing

Nothing is sold, shared or given to anyone. No data from Google is used for anything other than keeping and restoring these backups.

Stopping it

The owner can remove the tool's access at any time: Google Account → Security → Your connections to third-party apps & services. The backup folder can then be deleted in Google Drive.
